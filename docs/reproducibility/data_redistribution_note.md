# Data Redistribution Note

This repository contains a Paper 1 release package for the Meadows 1972 contextual bibliometrics project. The minimum release package intentionally excludes source PDFs.

Source PDFs may be subject to publisher, database, or copyright restrictions. Extracted full text may also require rights review, even when derived from locally available documents. For that reason, source PDFs and large extracted-text folders are not included in the minimum release package.

The release package includes final validation tables, figure source tables, methodology manifests, frozen v2.0 documentation, selected coded validation outputs, and derived non-infringing summaries used to support the Paper 1 methods claims.

Full reproduction of the extraction stage may require local access to source texts where redistribution is not permitted. Researchers who reproduce the workflow should provide their own legally accessible source documents, then compare derived validation and figure/table artifacts against the frozen release manifests where possible.

This note does not grant permission to redistribute third-party source documents. It records the release decision used for `v2.0-paper1-freeze`.
